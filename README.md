Sistema de información institucional desarrollado para centralizar y optimizar los procesos académicos y administrativos de una universidad. Está orientado a tres tipos de usuarios: estudiantes, profesores y personal administrativo, cada uno con acceso a las funcionalidades correspondientes a su rol.
El sistema busca facilitar tareas como la consulta de calificaciones, gestión de grupos, captura de información académica, generación de reportes y administración general del plantel, todo desde una sola plataforma accesible y organizada. Este proyecto tiene como objetivo modernizar y simplificar la experiencia escolar tanto para alumnos como para el personal docente y administrativo.
